# Hello, World! 🌎

O objetivo deste desafio é simples, mas fundamental: configurar o teu ambiente de desenvolvimento e escrever o teu primeiro programa em linguagem C.

## Especificação
No arquivo `hello.c`, escreva um programa em C que imprima exatamente a mensagem "hello, world" seguida de uma nova linha.

## Demonstração
```bash
$ make hello
$ ./hello
hello, world
```
