# Mario (Fácil) 🧱

No final do Mundo 1-1 do Super Mario Bros. da Nintendo, o Mario deve subir uma pirâmide de blocos antes de saltar para a bandeira. Vamos recriar essa pirâmide usando o terminal!

## Especificação
Num arquivo `mario.c`, implemente um programa que recria uma pirâmide usando `#` para os tijolos.
1. O programa deve pedir ao utilizador um número inteiro positivo para a **Altura** da pirâmide.
2. Se o utilizador fornecer um número menor que 1 ou maior que 8, o programa deve pedir o número novamente até que um valor válido seja inserido.
3. A pirâmide deve ser alinhada à direita usando espaços em branco.

## Demonstração
```bash
$ ./mario
Altura: 4
   #
  ##
 ###
####
```
