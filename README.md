# Eae, parça 🤝

Agora que já sabes imprimir texto, vamos aprender a receber dados do utilizador para tornar os teus programas interativos.

## Especificação
Num arquivo `eae.c`, cria um programa que:
1. Pergunte ao usuário "Qual é o seu nome?".
2. Armazene esse nome numa variável do tipo `string`.
3. Imprima a saudação "Eae, " seguida do nome fornecido.

## Demonstração
```bash
$ make eae
$ ./eae
Qual é o seu nome? Davi
Eae, Davi
```
