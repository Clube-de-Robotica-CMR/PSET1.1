# Mario (Difícil) 🧱🧱

Se o desafio anterior foi fácil, vamos aumentar a complexidade. Desta vez, o Mario precisa de duas pirâmides opostas com um "fosso" entre elas, exatamente como em alguns níveis clássicos.

## Especificação
Num arquivo `mario.c`, crie um programa que desenha duas pirâmides de altura variável:
1. Pede ao utilizador a **Altura** (entre 1 e 8).
2. Desenha a primeira pirâmide (alinhada à direita).
3. Adiciona um espaço fixo de **dois espaços** de largura entre as pirâmides.
4. Desenha a segunda pirâmide (espelhada, alinhada à esquerda).

## Demonstração
```bash
$ ./mario
Altura: 4
   #  #
  ##  ##
 ###  ###
####  ####
```
